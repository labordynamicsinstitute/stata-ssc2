About

ssc2 — install Stata packages from date-based snapshots of the SSC archive.

What it does

The SSC archive contains only the most recent version of each user-written Stata package. This means that when an author uploads an update, the previous version is no longer available. This creates challenges for reproducibility as researchers seeking to replicate older analyses may be unable to obtain the package versions originally used. The goal of ssc2 is to address this limitation by serving as a drop-in replacement for Stata's built-in ssc command that can install packages as they existed on a given date. It does so by using daily snapshots of the archive stored in the ssc-mirror repository, following the same general approach that dated CRAN snapshots introduced for the R ecosystem.

When no date is requested, ssc2 simply delegates to the official ssc command, ensuring that existing workflows continue to function unchanged.

Installation

net install ssc2, all replace from("https://raw.githubusercontent.com/labordynamicsinstitute/stata-ssc2/main")

Quick example

* the version of reghdfe that was current on 7 January 2022
ssc2 install reghdfe, date(2022-01-07)

* without date(), identical to -ssc install-
ssc2 install reghdfe, replace

The snapshot picker on the home page writes these commands for you. Snapshot coverage is daily from 2021-12-21, with a few earlier snapshots and known exceptions listed in the mirror's ERRATA.

Custom mirrors

Institutions can host an internal clone of the snapshot mirror (same layout) and point ssc2 at it with the from() option, or globally via the SSC2_MIRROR Stata global or environment variable — see the Reference for details.
